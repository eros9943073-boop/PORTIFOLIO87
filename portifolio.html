MINHAS HABILIDADES / 2026

O que estou aprendendo e desenvolvendo

01
ESTRUTURA WEB

HTML: a estrutura das páginas

Uma das minhas primeiras experiências com desenvolvimento web foi aprender HTML. Essa linguagem é responsável por organizar os elementos que aparecem em uma página, como títulos, parágrafos, imagens, links e formulários. Durante meus estudos, aprendi a utilizar diferentes tags para construir páginas com uma estrutura organizada.

Também venho trabalhando com HTML semântico, utilizando elementos como header, nav, main, section, article e footer. Entendi que desenvolver uma página não significa apenas colocar informações na tela, mas também organizar o conteúdo de maneira que os navegadores e mecanismos de busca consigam compreender melhor o site.

HTML5 Tags semânticas Formulários SEO
02
ESTILIZAÇÃO E DESIGN

CSS: dando identidade aos projetos

Depois de aprender a estruturar páginas com HTML, comecei a estudar CSS para trabalhar a aparência dos meus projetos. Com ele, consigo modificar cores, tamanhos, fontes, espaçamentos, bordas e organizar os elementos de diferentes maneiras.

Tenho aprendido a criar layouts utilizando Flexbox, Grid e responsividade. Uma das coisas que considero importantes é fazer com que um site funcione bem tanto em computadores quanto em celulares. Também procuro escolher combinações de cores e elementos visuais que deixem cada projeto organizado, agradável e fácil de utilizar.

CSS3 Flexbox Grid Responsividade Design
03
INTERATIVIDADE

JavaScript: criando funcionalidades

O JavaScript foi uma etapa importante na minha aprendizagem porque comecei a entender como tornar uma página interativa. Com ele, posso criar botões funcionais, validar formulários, responder às ações dos usuários e modificar elementos da página sem precisar recarregá-la.

Nos meus estudos, venho praticando variáveis, funções, condições, eventos e manipulação do DOM. Também comecei a utilizar JavaScript para conectar meus projetos a bancos de dados e trabalhar com informações recebidas de outros serviços. Quero continuar aprofundando meus conhecimentos para desenvolver sistemas cada vez mais completos.

JavaScript DOM Eventos Funções APIs
04
ARMAZENAMENTO DE DADOS

Banco de Dados: organizando informações

Outro conhecimento que venho desenvolvendo é o trabalho com bancos de dados. Aprendi que eles permitem armazenar, organizar, consultar e atualizar informações de maneira estruturada.

Durante o desenvolvimento do meu portfólio, comecei a utilizar o Supabase para conectar o site a um banco de dados. Com essa ferramenta, estou aprendendo a trabalhar com tabelas, registros, autenticação de usuários e operações de cadastro. Um dos meus desafios foi integrar o painel administrativo ao banco para cadastrar projetos e armazenar informações que poderão ser exibidas no site.

Supabase SQL Tabelas CRUD Autenticação
05
TECNOLOGIA E INOVAÇÃO

Inteligência Artificial: aprendendo com novas ferramentas

A inteligência artificial também faz parte da minha rotina de aprendizagem. Utilizo ferramentas de IA como apoio nos estudos e no desenvolvimento dos meus projetos. Elas me ajudam a compreender conceitos, identificar possíveis erros nos códigos, organizar ideias e encontrar diferentes maneiras de resolver problemas.

Um dos aprendizados mais importantes foi perceber que não basta copiar um código gerado por uma inteligência artificial. Procuro entender o que cada parte faz, testar as funcionalidades e analisar os resultados. Acredito que a IA é uma ferramenta que pode ampliar nossas possibilidades, mas que aprender, pensar e desenvolver nossas próprias soluções continua sendo fundamental.
